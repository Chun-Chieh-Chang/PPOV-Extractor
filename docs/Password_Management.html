1. 系統權限等級說明

PPOV Extractor 系統採用雙層角色控制架構（RBAC），在確保現場品質操作極簡高效的同時，也為管理端提供完整的功能維護能力：

  • 品質檢查員 (Inspector Mode)：預設預設模式（免登入/唯讀存取）。產線檢驗員開啟主畫面即可直接進行報告對比、規格檢視與查檢表填寫，完全隱藏所有敏感管理按鈕。
  • 系統管理員 (Admin Mode)：高階管理權限。擁有新增/編輯品號規格數據、清空資料庫、載入與導出 Excel 總表等全功能操作權限。
完全無密碼設計： 為徹底消除產線人員忘記密碼、密碼洩漏與後端維護 `users.json` 的複雜度，本系統採用先進的彩蛋連擊解鎖機制，完全免除密碼輸入與忘記密碼的煩惱。

2. 隱蔽式 5連擊解鎖機制

管理員權限採用隱蔽且無聲無息的彩蛋解鎖架構：

2.1 解鎖步驟

  1. 開啟 PPOV Extractor 系統主畫面。
  2. 在頁面右上角 Header 找到版本號標籤（如 v1.9.4）。
  3. 在 1.5 秒內連續點擊該標籤 5 次。
  4. 系統將精準過濾 1.5 秒滑動時間視窗內的點擊紀錄，達到 5 次時立即無縫切換為 [系統管理員 / ADMIN] 權限，展開管理控制面板。

2.2 鎖定與切換回檢查員模式

在管理員模式下，點擊右上角個人面板右側的「切換/登出圖示」，即可秒級切換回品質檢查員唯讀模式。

3. 資安防護與零密碼負擔

本系統將資安與使用體驗相結合，達成以下高度防護特點：

  • 零密碼洩漏風險：無存儲任何 plaintext 或 hashed 密碼檔案（已清理 `users.json`），徹底杜絕暴力破解與彩虹表攻擊。
  • 無提示無彈窗：連擊過程與解鎖後皆無聲無息，無任何 Tooltip 提示文字或彈窗干擾，實現最佳產線隱蔽性。
  • 滑動視窗防誤觸 (Sliding Window Algorithm)：採用 `now - t <= 1500` 精準計時過濾，防止無意間點擊累積導致的誤解鎖。

4. GitHub Pages 靜態與本地端權限同構

不論是在產線本機運行的 Python Flask 後端環境，或是在 GitHub Pages 靜態展示頁面中，5連擊解鎖機制均保持 100% 運作一致性：

在 GitHub Pages 環境下，解鎖後全數數據新增、修改、刪除與導出操作均於瀏覽器前端記憶體純化執行（Zero-Server Upload），數據 100% 保留在本機，提供最頂級的資訊安全。
